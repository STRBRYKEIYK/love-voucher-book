# Love Voucher Book

A one-page love voucher booklet for Chicaaaaa: 7 redeemable vouchers and a scratch-to-reveal surprise.

Plain HTML, CSS and JavaScript. No build step.

## Run it

Open `index.html` in a browser, or serve the folder with any static host (Vercel, GitHub Pages, Netlify).

## Notes

- Redeemed vouchers are remembered in the browser (`localStorage`), per device.
- Tapping a redeemed voucher's "Ipadala kay Chicooo" button opens WhatsApp with a ready message.
